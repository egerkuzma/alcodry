# alcodry для macOS

Клиент в строке меню. Показывает **2/14** или **окно 3д**, по клику — меню с
теми же действиями, что и на веб-морде. Своей базы у него нет: это тонкий клиент
к домашнему серверу, ходит в тот же JSON API.

```
[лестница] 2/14
  День 2 из 14
  Этап 2 из 5, цикл №1
  Этап до 30 августа
  ─────────────────
  Сорвался
  Этап закрыт            (неактивно, пока срок не вышел)
  ─────────────────
  Открыть в браузере
  Обновить
  Адрес сервера…
  Запускать при входе    ✓
  ─────────────────
  Выйти
```

В режиме окна вместо двух первых действий — «Выпил» и «Начать этап сейчас».

## Установка

```sh
./build.sh
open build/alcodry.dmg
```

Нужны только Command Line Tools, ни Xcode, ни зависимостей: один файл на Swift,
`swiftc`, `iconutil` и `hdiutil`. На выходе `build/alcodry.app` и
`build/alcodry.dmg` — образ на 126 КБ.

Дальше по шагам:

1. Перетащить приложение из образа в «Программы». Именно туда, а не запускать
   из каталога сборки: он пересоздаётся при каждом `build.sh`, и автозапуск
   будет ссылаться в пустоту.
2. Первый раз открыть правым кликом → «Открыть». Приложение подписано ad-hoc,
   и Gatekeeper спросит про неизвестного разработчика — один раз.
3. Разрешить доступ к локальной сети, когда macOS спросит. Без этого до
   домашнего сервера клиент не достучится.
4. Если сервер не `kuzmich-serv:7777` — поправить в меню, «Адрес сервера…».
5. Поставить галочку «Запускать при входе», если нужно.

Иконка появится в правой части строки меню, рядом с часами.

## Что нужно знать

**Подписи разработчика нет.** Хватает ad-hoc, иначе на Apple Silicon бинарник не
запустился бы вовсе. Нотаризация, которая убрала бы предупреждение Gatekeeper,
требует Apple Developer за $99 в год и домашнему клиенту ни к чему.

**Адрес сервера** по умолчанию `http://kuzmich-serv:7777`, меняется в меню и
запоминается в `UserDefaults`. Работает только в домашней сети: снаружи сервер
не виден, так что вне дома клиент покажет прочерк.

**Иконки в Dock нет** — приложение живёт в строке меню (`LSUIElement`).

**Автозапуск** — галочка «Запускать при входе» в меню, через `SMAppService`.
Регистрируется тот бандл, из которого приложение запущено, поэтому сначала
перетащи его в «Программы», а потом включай галочку: иначе система будет
поднимать копию из каталога сборки, а он пересоздаётся при каждом `build.sh`.
Выключается там же, отдельно лезть в системные настройки не нужно.

**Если иконки не видно.** На ноутбуках с вырезом под камеру строка меню разорвана
надвое, и элемент может встать ровно под вырезом — он есть, но невидим. При
первом запуске приложение само кладёт себя к правому краю (`NSStatusItem
Preferred Position alcodry` = 0). Если потом перетащить иконку Cmd-мышью в
середину, она снова пропадёт, а позиция запомнится. Лечится сбросом:

```sh
defaults delete dev.egerkuzma.alcodry "NSStatusItem Preferred Position alcodry"
```

и перезапуском приложения.

## Как устроено

Один файл, [`Sources/main.swift`](Sources/main.swift), около трёхсот строк.
Раз в минуту и при каждом открытии меню дёргает `GET /api/status`, рисует по
ответу заголовки и кнопки. Действия — те же `POST`, что и у веб-морды; на 409
показывает объяснение сервера («Этап идёт до 30 августа, осталось 13 дней»).
Никакого своего состояния клиент не хранит, поэтому разъехаться с сервером ему
нечем.

Проверить связь без интерфейса:

```sh
./build/alcodry.app/Contents/MacOS/alcodry --probe http://kuzmich-serv:7777
```

Печатает то, что оказалось бы в строке меню, и выходит.
